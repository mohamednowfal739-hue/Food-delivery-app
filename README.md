# Crave — Food Delivery Website Prototype

A responsive food delivery website built with HTML, CSS, and vanilla JavaScript.

## Run it
1. Extract `crave-food-delivery.zip`.
2. Open `index.html` in a browser. For a smoother local development workflow, use VS Code's Live Server extension.

## Features
- Restaurant listings with search and cuisine filters
- Individual restaurant menus
- Add-to-cart and quantity controls
- Prevents mixing items from different restaurants in one order
- Delivery fee and total calculation in Indian rupees
- Checkout form with name, phone, address, and optional note
- Responsive desktop and mobile layout
- Favourite restaurant toggle
- Demo order confirmation

## Important
This is a front-end prototype. Checkout is simulated in the browser: it does not transmit orders, store customer data, process payments, or connect to restaurant systems. Before launch, add a backend/API, database, authentication, secure payment gateway, restaurant order dashboard, and delivery/status workflow. The food photography and Google Fonts use external URLs and require an internet connection.
